Pusat Bantuan & FAQ

Pahami arti status dan solusi kendala pengiriman Anda

Apa arti status "Manifested" atau "Shipment Received"?

Paket sudah diserahkan oleh pengirim ke pihak ekspedisi dan data pengiriman telah terdaftar di sistem pusat.

Apa arti "On Process" / "In Transit"?

Paket sedang dalam perjalanan darat/udara antar kota/hub transit ekspedisi menuju kota tujuan.

Apa arti "With Courier" / "Sedang Diantar"?

Paket sudah tiba di agen/hub tujuan terdekat dan saat ini dibawa oleh kurir menuju alamat rumah Anda.

Apa yang harus dilakukan jika resi "Tidak Ditemukan"?

Pastikan pilihan nama kurir sudah sesuai dan nomor resi tidak ada salah ketik. Resi baru umumnya membutuhkan waktu 1-3 jam untuk terupdate di server ekspedisi.

Apakah data di SatuTujuan terupdate secara real-time?

Ya, data status pelacakan diambil secara langsung (real-time) dari server resmi masing-masing penyedia layanan kurir.
